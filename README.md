# موقع عاشق العود — صفحة عطور عربية (أسود/دهبي)

موقع ثابت (Static) من صفحة واحدة: HTML + CSS + JavaScript فقط، بدون أي سيرفر أو قاعدة بيانات.

## التشغيل محليًا
افتح ملف `index.html` مباشرة في المتصفح، أو شغّل سيرفر بسيط:
```
python3 -m http.server 8000
```
ثم افتح http://localhost:8000

## المحتوى
- **الرئيسية**: تعريف بالبراند بصورة الغلاف الأصلية من الكتالوج.
- **من نحن**: نبذة عن البراند + 3 مميزات.
- **العطور**: 6 منتجات (الأسماء، الأوصاف، مكونات الريحة، الأحجام والأسعار مأخوذة حرفيًا من كتالوج PDF الأصلي).
- **تواصل معنا**: زر تواصل عام عبر واتساب.

## الطلب عبر واتساب
كل منتج له زر "اطلب الآن عبر واتساب" يفتح محادثة مع رقم البراند برسالة جاهزة فيها اسم العطر، مثال:
«أهلاً، عايز أطلب عطر عود ملكي من عاشق العود»

## ملاحظات
- صور الزجاجات رسوم توضيحية أصلية (SVG) وليست صور المنتجات الفعلية، وده مكتوب بوضوح تحت كل منتج وفي ملاحظة أسفل القسم.
- الموقع متجاوب (موبايل + كمبيوتر) واتجاهه RTL بالكامل.
- الخطوط من Google Fonts (Cairo + Amiri) مع بدائل نظام تعمل بدون إنترنت.
- ينفع يتنشر على أي استضافة ملفات ثابتة (Static hosting) كما هو.
